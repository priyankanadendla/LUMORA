LUMORA — ADVANCED TRAVEL DISCOVERY

Frontend-only project for VS Code.

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted lumora-advanced folder in VS Code.
3. Open index.html and run with Live Server (Go Live), or double-click index.html to open it in a browser.

FEATURES
- Cinematic photographic destination backgrounds with motion effects.
- Search and category filters.
- Save favourite destinations in browser storage.
- Destination detail modals, theme controls and surprise destination.
- World Explorer, Trip Planner dashboard and Dream Board dashboard open in new tabs.
- Advanced trip planner: destination, date, traveller count, duration, style, transport, adjustable budget, estimated breakdown, starter itinerary, save/copy/print.
- Responsive layout and reduced-motion support.

NOTES
This is a frontend demonstration; no backend or live booking API is connected. Image backgrounds are loaded from Unsplash URLs and require an internet connection. Ratings and costs are illustrative estimates, not live verified data.
